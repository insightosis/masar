الوحدة الثانية: الدوال الحقيقية

مجال الدالة

الدالة مثل آلة: تدخل فيها x وتطلع لك قيمة y واحدة. بس بعض الآلات ترفض بعض الأرقام: آلة الجذر التربيعي ترفض السالب، وآلة الكسر ترفض اللي يصفّر المقام. المجال هو قائمة الأرقام اللي تقبلها الآلة.

آلة الدالة

مقبول (داخل المجال)مرفوض

جرّب تحط x على الأرقام الحرجة: 2 مع الجذر، 3 مع الكسر، 0 مع الجذر اللي في المقام. وشوف الفرق بين النقطة المملوءة (مقبولة) والفارغة (مرفوضة).

العلاقة والدالة

من كتابك: اربط كل صديق بسنة ولادته: كل اسم يرتبط بسنة واحدة بالضبط. أما لو ربطته بالرياضات اللي يحبها: ممكن اسم يرتبط بأكثر من رياضة، أو ما يرتبط بأي رياضة. الأول دالة، والثاني علاقة فقط.

الدالة: عندما يكون كل عنصر في المجال مرتبطاً بعنصر واحد فقط من المجال المقابل. وإذا كان المجال والمجال المقابل مجموعتين جزئيتين من الأعداد الحقيقية، تسمى دالة حقيقية.

مجال الدالة

إذا كانت y = f(x) دالة، فمجالها D هو مجموعة كل الأعداد الحقيقية اللي يأخذها المتغير x وينتج عنها قيم حقيقية للمتغير y. ونقول: الدالة معرّفة على المجال D.

عندنا "خطران" فقط يسرقون أرقاماً من المجال:

جذر زوجي (تربيعي)

ما في جذر تربيعي حقيقي لعدد سالب، فالمجذور لازم ≥ 0 (موجب أو صفر).

مقام

القسمة على صفر ممنوعة، فنحذف أصفار المقام.

أما كثيرات الحدود، والجذر التكعيبي (أي جذر فردي)، والقيمة المطلقة: ما تسرق شي.

القواعد الثماني

1) كثيرة الحدود

D = ℝ

مثل x² + 3x + 1

2) الحدودية النسبية

D = ℝ / {أصفار المقام}

البسط والمقام كثيرتا حدود.

3) القيمة المطلقة

f(x) = |x| : D = ℝ

4) جذر دليله n زوجي

f(x) = ng(x)

المجال: قيم x اللي تحقق g(x) ≥ 0

5) جذر دليله n فردي

f(x) = ng(x)

المجال = مجال g

6) جمع أو طرح

f = g ± h : Df = Dg ∩ Dh

7) ضرب

f = g · h : Df = Dg ∩ Dh

8) قسمة

f = gh : (Dg ∩ Dh) / {h(x) = 0}

المشترك، عدا أصفار المقام (h(x) ≠ 0)

مثال محلول: جذر فوق مقام

أوجد مجال f(x) = x + 2x − 3
  1. سمِّ الأجزاء: البسط g(x) = x + 2 والمقام h(x) = x − 3
  2. مجال البسط (جذر زوجي): x + 2 ≥ 0 ⇒ x ≥ −2 أي [−2, ∞)
  3. مجال المقام: ℝ (كثيرة حدود)، وأصفاره: x − 3 = 0 ⇒ x = 3
  4. القاعدة 8: ([−2, ∞) ∩ ℝ) / {3}
  5. المجال [−2, 3) ∪ (3, ∞)

اكتب الجواب نشاط

مجال u(x) = 5x² − 9 هو ℝ − {−a, a}. اكتب قيمة a الموجبة.

النقاط الذهبية

اللي يحبّه الاختبار، والفخاخ اللي يطيح فيها أغلب الطلاب.

في حياتك

آلة البيع

كل زر يعطيك منتجاً واحداً: دالة. زرّان يعطيان نفس العصير؟ عادي، ما زالت دالة. لكن زر يطلّع مرة عصير ومرة شوكولاتة: مو دالة.

الآلة الحاسبة

اكتب √(−4) أو 5 ÷ 0 وبتشوف Error: الرقم خارج المجال.

البطاقة المدنية

كل شخص له تاريخ ميلاد واحد: الربط من الشخص إلى تاريخ ميلاده دالة.

الصحيح: ℝ. الجذر التكعيبي (دليل فردي) معرّف لكل عدد حقيقي، حتى السالب، فلا شروط.

مجال h(x) = xx + 2 هو:

الصحيح: x + 2 = 0 ⇒ x = −2. نستبعد صفر المقام، والبسط ما يهمّ حتى لو صار صفراً.

احفظ هذه الثلاث

  1. الدالة: كل عنصر في المجال مرتبط بعنصر واحد فقط من المجال المقابل. وبالرسم: كل مستقيم رأسي يقطع البيان في نقطة واحدة على الأكثر.
  2. المجال: كل قيم x اللي تعطي y حقيقية. كثيرة الحدود والجذر الفردي والقيمة المطلقة: ℝ. الجذر الزوجي: المجذور ≥ 0. الكسر: نحذف أصفار المقام.
  3. الدوال المركّبة: جمع أو طرح أو ضرب: تقاطع المجالين. قسمة: التقاطع عدا أصفار المقام.
