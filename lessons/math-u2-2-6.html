المتباينة التربيعية وجدول الإشارات

الفكرة بسيطة: حاصل ضرب عاملين موجب إذا كانا بنفس الإشارة، وسالب إذا اختلفا. والإشارة ما تتغير إلا عند الأصفار. فنقسم خط الأعداد عند الأصفار، ونقرأ إشارة كل قطعة.

اجعل الطرف الأيسر صفراً (انقل كل الحدود لطرف واحد).
حلّ المعادلة المناظرة بالتحليل، وأوجد الأصفار.
كوّن جدول الإشارات: إشارة كل عامل في كل فترة، ثم إشارة حاصل الضرب.
اختر الفترات اللي إشارتها تطابق المتباينة. مع ≤ أو ≥ تدخل الأصفار.

مثال (1)

أوجد مجموعة حل المتباينة: x² − x − 6 < 0
  1. المعادلة المناظرة: x² − x − 6 = 0 ⇐ نحلل: (x + 2)(x − 3) = 0
  2. الأصفار: x = −2 أو x = 3. و x + 2 > 0 لما x > −2، و x − 3 > 0 لما x > 3.
  3. جدول الإشارات (نبحث عن السالب):
  4. مجموعة الحل = (−2, 3)
حاول أن تحل (1): x² + 4x + 3 ≤ 0

(x + 1)(x + 3) ≤ 0، الأصفار −3 و −1، والحاصل سالب بينهما. ومع ≤ يدخل الصفران: [−3, −1].

رتّب الخطوات نشاط

عندك x² + 5x > 6. رتّب خطوات الحل. فيه قطعة زائدة.

مثال (2): معامل x² سالب

أوجد مجموعة حل المتباينة: −x² + 7x − 10 ≤ 0

تذكّر

عند ضرب طرفي متباينة في عدد سالب نعكس علاقة الترتيب. ويمكنك الضرب في (−1) للسهولة.

  1. نضرب في −1 ونعكس: x² − 7x + 10 ≥ 0
  2. المعادلة المناظرة: (x − 2)(x − 5) = 0 ⇐ x = 2 أو x = 5
  3. نبحث عن الموجب أو الصفر:
  4. مجموعة الحل = (−∞, 2] ∪ [5, ∞) أو ℝ/(2, 5)
حاول أن تحل (2): −2x² + 5x − 3 > 0

نضرب في −1: 2x² − 5x + 3 < 0 ⇐ (2x − 3)(x − 1) < 0. الأصفار 1 و 3/2، والحاصل سالب بينهما: (1, 3/2).

4

تطبيق حياتي: حديقة مستطيلة

مثال (3): حديقة مستطيلة محيطها 20 m وطول أحد بعديها x. a) ما المجال الواقعي لـ x؟ b) عبّر عن دالة المساحة f بدلالة x. c) حلّ f(x) < 24. d) حلّ f(x) > 9.

جرّب بنفسك: غيّر البعد x

  1. a) P = 2(L + W) = 20 ⇐ L + W = 10. البعد الآخر 10 − x، والبعدان موجبان، فالمجال الواقعي x ∈ (0, 10)
  2. b) المساحة = الطول × العرض: f(x) = x(10 − x) = −x² + 10x
  3. c) −x² + 10x − 24 < 0 ⇐ (−x + 4)(x − 6) < 0، الأصفار 4 و 6. نكوّن الجدول مع مراعاة x ∈ (0, 10):
    مجموعة الحل = (0, 4) ∪ (6, 10)
  4. d) −x² + 10x − 9 > 0 ⇐ (−x + 1)(x − 9) > 0، الأصفار 1 و 9:
    مجموعة الحل = (1, 9)

انتبه: الجدول هنا يبدأ من 0 وينتهي عند 10، مو من −∞ إلى ∞، لأن البعد لا يكون سالباً ولا أكبر من 10.

حاول أن تحل (3): محيط مستطيل 16 m، و f(x) > 7

المجال الواقعي (0, 8)، والمساحة f(x) = x(8 − x) = −x² + 8x. −x² + 8x − 7 > 0 ⇐ (−x + 1)(x − 7) > 0 ⇐ مجموعة الحل (1, 7).

تطبيق على مجال الدالة الجذرية

تذكّر من درس المجال: ما فيه جذر تربيعي لعدد سالب. فمجال √(…) هو كل x اللي تخلي ما تحت الجذر ≥ 0. يعني: متباينة!

مثال (4a)

أوجد مجال f(x) = x² − 4
  1. الشرط: x² − 4 ≥ 0 ⇐ (x − 2)(x + 2) = 0 ⇐ x = 2 أو x = −2
  3. المجال: (−∞, −2] ∪ [2, +∞) = ℝ/(−2, 2)

مثال (4b)

أوجد مجال g(x) = −x² + 4x − 3
  1. الشرط: −x² + 4x − 3 ≥ 0 ⇐ (−x + 1)(x − 3) = 0 ⇐ الأصفار 1 و 3
  3. المجال: [1, 3]
حاول أن تحل (4): طريقة ثانية، و h(x) = √(x² − x)

a) طريقة أخرى لـ y = √(x² − 4): الشرط x² ≥ 4، يعني العدد مربّعه 4 أو أكثر، فـ x ≤ −2 أو x ≥ 2. ويمكنك أيضاً قراءته من بيان y = x² − 4: الجزء اللي فوق محور السينات أو عليه.

متباينات فيها حدوديات نسبية

هنا عندنا كسر. والكسر مثل الضرب: موجب إذا البسط والمقام بنفس الإشارة. الفرق الوحيد: صفر المقام ممنوع، الكسر غير معرّف هناك، فلا يدخل الحل أبداً حتى مع ≥.

انقل كل شيء لطرف واحد ليصير الطرف الآخر 0 (لا تضرب في المقام: ما نعرف إشارته).
وحّد المقامات وبسّط حتى يصير كسراً واحداً، وحلّل البسط.
أوجد أصفار البسط وأصفار المقام (قبل أي اختصار).
جدول الإشارات، وعند صفر المقام اكتب "غير معرّفة".

مثال (5)

أوجد مجموعة حل المتباينة: 3x + 7x + 2 ≥ 2
  1. انقل 2: 3x + 7x + 2 − 2 ≥ 0 ⇐ مقام مشترك: 3x + 7 − 2x − 4x + 2 ≥ 0 ⇐ x + 3x + 2 ≥ 0
  2. صفر البسط x = −3، وصفر المقام x = −2
  4. مجموعة الحل: (−∞, −3] ∪ (−2, ∞) = ℝ/(−3, −2] لاحظ: −3 داخلة (البسط صفر مسموح)، و −2 خارجة (صفر المقام).
حاول أن تحل (5): (3x − 5) ÷ (−2x + 3) ≥ 0

صفر البسط 5/3، وصفر المقام 3/2. قبل 3/2: البسط سالب والمقام موجب (سالب). بين 3/2 و 5/3: الاثنان سالبان (موجب). بعد 5/3: البسط موجب والمقام سالب (سالب). مجموعة الحل (3/2, 5/3].

مثال محلول (6): ثلاثة أصفار

أوجد مجموعة حل المتباينة: x² − 5x + 3x + 4 < 3
  1. انقل 3 ووحّد المقام: x² − 5x + 3 − 3x − 12x + 4 < 0
  2. بسّط وحلّل البسط: x² − 8x − 9x + 4 = (x + 1)(x − 9)x + 4 < 0
  3. أصفار البسط: x = −1 أو x = 9. صفر المقام: x = −4
  4. ثلاثة عوامل، فثلاثة صفوف، ثم الكسر كله:
  5. مجموعة الحل = (−∞, −4) ∪ (−1, 9)
حاول أن تحل (6): (x² + 5x) ÷ (x + 3) > −2

نجمع 2: (x² + 5x + 2x + 6) ÷ (x + 3) > 0 ⇐ (x + 1)(x + 6) ÷ (x + 3) > 0. الأصفار −6 و −1، وصفر المقام −3. الإشارات من اليسار: − , + , − , +. مجموعة الحل (−6, −3) ∪ (−1, ∞).

مثال (7): احذر من الاختصار

أوجد مجموعة حل المتباينة: x² − 5x + 6x − 3 > 0
  1. حلّل البسط: (x − 2)(x − 3)x − 3 > 0
  2. قبل التبسيط نحدد صفر المقام: x = 3، فـ x ≠ 3
  3. نختصر: x − 2 > 0 ⇐ x > 2
  4. مجموعة الحل = (2, ∞)/{3} = (2, 3) ∪ (3, ∞)

فخ: لو اختصرت أولاً، تنسى أن 3 ممنوعة وتكتب (2, ∞)، وهذا خطأ. من المهم جداً تحديد أصفار المقام قبل الاختصار.

حاول أن تحل (7): (x² − 49) ÷ (x + 7) ≤ 0

x ≠ −7 أولاً. ثم (x − 7)(x + 7) ÷ (x + 7) = x − 7 ≤ 0 ⇐ x ≤ 7. مجموعة الحل (−∞, −7) ∪ (−7, 7].

الحل بالرسم البياني

مثال (8): بيان f(x) = x² + 2x − 3 والمستقيم y = 5. a) ادرس بيانياً f(x) < y. b) ادرس بيانياً f(x) > y. c) تحقّق حسابياً.
  1. a) المستقيم يقطع المنحنى في (−4, 5) و (2, 5). المنحنى تحت المستقيم بينهما: f(x) < 5 ∀x ∈ (−4, 2)
  2. b) المنحنى فوق المستقيم خارجهما: f(x) > 5 ∀x ∈ (−∞, −4) ∪ (2, ∞)
  3. c) حسابياً: x² + 2x − 3 < 5 ⇐ x² + 2x − 8 < 0 ⇐ (x − 2)(x + 4) < 0
    نفس النتيجة.
حاول أن تحل (8): f(x) = x² − 6x + 5 و y = −3

اختر الدالة الرابعة في المختبر وضع c = −3. نقطتا التقاطع عند x = 2 و x = 4 (لأن x² − 6x + 8 = (x − 2)(x − 4)). إذن f(x) = y عند x ∈ {2, 4}، و f(x) < y لكل x ∈ (2, 4)، و f(x) ≥ y لكل x ∈ (−∞, 2] ∪ [4, ∞).

المرشد لحل المسائل: رحلة ذهاب وعودة

المسافة بين مدينتين 300 km. سرعة السيارة ذهاباً x km/h، وعودةً (x − 20) km/h، والرحلة كلها 5 h 30 min. أوجد السرعتين.
  1. الزمن = المسافة ÷ السرعة، و 5 h 30 min = 5.5 h: 300x + 300x − 20 = 5.5
  2. نضرب في المقام المشترك ونبسّط: 5.5x² − 710x + 6000 = 0 ⇐ 1.1x² − 142x + 1200 = 0
  3. نحل (بالمربع الكامل أو القانون العام): x = 120 أو x ≈ 9.1. الثانية مرفوضة: سرعة العودة x − 20 تصير سالبة.
  4. السرعة ذهاباً 120 km/h وعودةً 100 km/h
مسائل إضافية من الكتاب (الأجوبة)

1) لو كانت الرحلة 7 h 30 min: 300/x + 300/(x − 20) = 7.5 ⇐ x² − 100x + 800 = 0 ⇐ x ≈ 91.2 km/h ذهاباً و ≈ 71.2 km/h عودةً.

2) ربح محل الحواسيب f(x) = −x² + 250x − 2400 حيث x ثمن الحاسوب بالدينار: a) f(100) = 12600 دينار. b) أكبر ربح عند الرأس x = −b ÷ 2a = 125 ديناراً. c) أكبر ربح f(125) = 13225 ديناراً.

احفظ هذه الثلاث

  1. الخطوات: اجعل الطرف صفراً، أوجد أصفار المعادلة المناظرة، كوّن جدول الإشارات، واختر الفترات. ≤ و ≥ تُدخل الأصفار.
