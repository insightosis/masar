صنّف نشاط

أي هذه معادلات جذرية؟

أربع خطوات لأي معادلة جذرية

  1. افصل الجذر في طرف لوحده.
  2. حدّد شرط الحلدليل زوجي: ما تحت الجذر ≥ 0، وكل من الطرفين ≥ 0 أيضاً. دليل فردي: ما تحت الجذر ينتمي إلى ℝ (لا شرط).
  3. ارفع الطرفين لأس مناسب يحذف الجذر.
  4. تأكّد أن الحل يحقق الشرط.
مثال الكتاب (1a)2 + 3x − 2 = 6 ⇒ 3x − 2 = 4
الشرط: 3x − 2 ≥ 0 أي x ∈ [2/3, ∞). نربّع: 3x − 2 = 16 ⇒ x = 6 ✓
مجموعة الحل = {6}
مثال الكتاب (1b)6 + x − 1 = 3 ⇒ x − 1 = −3
جذر تربيعي = عدد سالب؟ مستحيل، لأن الجذر التربيعي دائماً موجب أو صفر.
مجموعة الحل = φ

معادلة فيها أس كسري

المعادلة xm/n = b نحلّها برفع الطرفين إلى الأس n/m (المعكوس الضربي للأس). وتذكّر: مقام الأس النسبي هو دليل الجذر.

إذا m زوجي

(xm/n)n/m = |x|

فيطلع حلّان: |x| = b يعني x = b أو x = −b.

إذا m فردي

(xm/n)n/m = x

حل واحد مباشرة.

مثال الكتاب (2): 2(x − 2)2/3 = 50 ⇒ (x − 2)2/3 = 25 ⇒ |x − 2| = 253/2 = 253 = 56 = 125
إذن x − 2 = 125 أو x − 2 = −125، و مجموعة الحل = {−123 , 127}

الحلول الدخيلة

رفع الطرفين لقوّة قد يعطي حلولاً دخيلة لا تحقق الشرط. لهذا الشرط مو زيادة: هو اللي يكشفها. هذا بالضبط ما رأيته في المختبر فوق.

مثال الكتاب (3): أوجد مجموعة الحل 5 + x − 3 = x
  1. افصل الجذر: x − 3 = x − 5
  2. الشرط: x − 3 ≥ 0 , x − 5 ≥ 0 أي x ≥ 5، يعني x ∈ [5, ∞)
  3. ربّع وفك: x − 3 = x2 − 10x + 25 ⇒ x2 − 11x + 28 = 0
  4. حلّل: (x − 4)(x − 7) = 0 ⇒ x = 4 أو x = 7
  5. 4 ∉ [5, ∞) فهو حل دخيل، و 7 ∈ [5, ∞). مجموعة الحل = {7}

جذران في معادلة واحدة

نفصلهما بحيث يكون في كل طرف جذر، ثم نربّع.

مثال الكتاب (4a)8x = 24x − 16
الشرط: 4x − 16 ≥ 0 و 8x ≥ 0 أي x ∈ [4, ∞). نربّع: 8x = 4(4x − 16) ⇒ 2x = 4x − 16 ⇒ x = 8 ✓
مجموعة الحل = {8}
مثال الكتاب (4b)x + 2x − 4 = 0 ⇒ x = −2x − 4
موجب = سالب؟ فقط لو الاثنان صفر: x = 0 ⇒ x = 0، و √(2x − 4) = 0 ⇒ x = 2. ما في x واحد يصفّرهما معاً.
مجموعة الحل = φ

ثانياً: المعادلات الأسية

المعادلات 2x = 32 , (−3)x = −243 , (½)y = 5 معادلات أسية. الفكرة: نكتب الطرفين بنفس الأساس، ثم نساوي الأسس.

الخاصية: ليكن a عدداً حقيقياً حيث a ∉ {−1, 0, 1}، و m, n عددان صحيحان. إذا كان am = an فإن m = n.

ليش استثنينا −1 و 0 و 1؟ لأن قوى هذه الأعداد تتشابه مع أسس مختلفة:

117 = 118 لكن 17 ≠ 18
(−1)13 = (−1)3 لكن 13 ≠ 3
04 = 03 لكن 4 ≠ 3

مثال الكتاب (6):

2x = 64 = 26 ⇒ x = 6
(½)x = 0.5 = (½)1 ⇒ x = 1

(3/4)x = 64/27 = (4/3)3 = (3/4)−3 ⇒ x = −3 (قلب الكسر يقلب إشارة الأس)

الأس ممكن يكون كثيرة حدود

مثال الكتاب (7a)3x²−1 = 27 = 33 ⇒ x2 − 1 = 3 ⇒ x2 = 4
مجموعة الحل = {−2 , 2}
مثال الكتاب (7b)7x²−3x = 1/49 = 7−2 ⇒ x2 − 3x + 2 = 0 ⇒ (x − 1)(x − 2) = 0
مجموعة الحل = {1 , 2}
مثال الكتاب (7c)62x−8 = 1 = 60 ⇒ 2x − 8 = 0
تذكّر a⁰ = 1, a ≠ 0
مجموعة الحل = {4}
